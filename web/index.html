反方向：CODE V → Zemax

浏览器读不了 CODE V 的镜头数据库，所以 CODE V → Zemax 这一边用宏 CV2ZMX.seq，在 CODE V 里直接写出 .zmx，不经过 Zemax 的 .seq 导入器。

  1. 下载 CV2ZMX.seq 和 CV2ZMX_GLASS.DAT，放在同一台电脑的任意目录。
  2. 打开 CV2ZMX.seq，把顶部 Settings 区的 ^gtable 改成 CV2ZMX_GLASS.DAT 的完整路径。
  3. 在 CODE V 命令行运行 in E:\tools\cv2zmx\CV2ZMX 输出文件名，结果写在 CODE V 当前工作目录。

对应关系

每一行都是 CV2ZMX 宏的逆运算，两个方向用同一套公式。

Zemax .zmxCODE V .seq说明
VDY / VCY, VDX / VCXVUY = VCY − VDY
VLY = VCY + VDY		Zemax 说剩下的光瞳在哪、多宽；CODE V 说上下各切掉多少。X 方向同理。
FNUM v 1（近轴工作 F/#）FNO，有限共轭 FNO² = PWFN² + (β/2)²两边入瞳一致；无限远时数值不变。
FNUM v 0（像方 F/#）FNO；有限共轭改写 EPD = EFL / F#像方 F/# 按无限远共轭定义，CODE V 的 FNO 是工作 F 数。
ENPD / OBNA / FLOAEPD / NAO / 由光阑半口径换算
EVENASPH PARM 2…8ASP：A B C D E F Gr⁴ … r¹⁶。CONI 就是 K。
XASPHERE XDAT 4…12ASP：A … J（到 r²⁰）归一化半径 Rn ≠ 1 时系数除以 Rn²ⁱ。
r² 项、奇次项、r²⁰ 以上SPS ODD（C1 = K，C(n+1) = rⁿ）ASP 放不下时才用，会提示核对。
BINARY_2DIF DOE，HCO Cj = Aj·λ0/2πλ0 取主波长，会提示核对焦距。
GLAS 牌号牌号_厂家（CV2ZMX_GLASS.DAT 反查）同名牌号按 GCAT 里的目录取舍，例如 D-QK3L → DQK3L_CDGM。
GLAS ___BLANK nd vd模型玻璃 nnnnnn.vvvv例如 1.5168 / 64.17 → 516800.6417。
MIRROR / COORDBRKREFL / 哑面＋XDE YDE ADE BDE CDE倾斜方向请在 CODE V 里画图核对。
CLAP、FLAP、固定半口径 / OBSCCIR / CIR OBS非圆形口径不转换，会列出来。
TOLE from len（位置求解）THI Sk OAL Sfrom..k+1 len该面不再写 ZOO THI，否则会覆盖求解。
MNUM + MCE（THIC CRVT CONN PRAM EDVA APER YFIE FVDY …）ZOO n + ZOO THI / CUY / K / A… / FNO / YAN / VUY …变量状态写成 ZOO THC 0，其余 100。
